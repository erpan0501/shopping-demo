# Java 商城项目

## 项目简介

这是一个包含商城端、管理端和 Java 服务端的本地演示项目。商城端用于浏览商品、搜索、查看详情、加入购物车和提交本地演示订单；管理端提供后台页面入口；Java 服务端提供演示接口与健康检查。

项目已按“展示优先”的方式整理：启动时只运行一个轻量 Java 演示服务和两个 Vue 前端，不要求配置注册中心、消息队列、搜索引擎或其他微服务基础设施。商城端默认使用本地演示数据，因此在没有接口数据时仍可完整浏览主要页面。

## 项目组成

| 模块 | 位置 | 说明 |
| --- | --- | --- |
| 商城端 | `前端/shopping_client/` | Vue 商城页面：商品浏览、搜索、详情、购物车、订单演示 |
| 管理端 | `前端/vue3-admin-main/` | Vue 后台管理页面入口 |
| Java 演示后端 | `shopping_demo/` | Spring Boot 演示服务，端口 `8090` |
| 原有扩展模块 | 根目录其他 Maven 模块 | 商品、订单、搜索、支付等扩展源码；本地演示不启动 |

## 环境要求

- macOS（提供双击可运行的 `.command` 脚本）。
- Java 17、Maven、Node.js（含 npm）。
- 首次启动时需要联网安装两个前端的依赖。

本地演示不依赖 MySQL、Nacos、Redis、RocketMQ、Elasticsearch 或 Docker。

## 一键启动

在 Finder 中双击根目录的 `启动.command`，或在终端进入项目目录后运行：

```bash
./启动.command
```

脚本会检查端口、安装首次依赖、同时启动 Java 后端和两个前端，并自动打开商城端。启动完成后可访问：

| 地址 | 用途 |
| --- | --- |
| `http://localhost:8081` | 商城端（建议从此处开始演示） |
| `http://localhost:8082` | 管理端页面 |
| `http://localhost:8090/api/demo/health` | Java 后端健康检查 |

## 商城端演示范围

- 首页商品分类与推荐商品展示。
- 商品搜索、筛选、商品详情。
- 加入购物车、数量调整、结算和本地订单展示。
- 商品图片均为仓库内本地资源，演示时不依赖外部图片链接。
- 本地演示数据保存在浏览器会话中；刷新、清理浏览器数据或更换浏览器后可能恢复默认状态。

## 管理端与后端说明

管理端用于展示后台管理界面。Java 服务端当前仅保留适合本机演示的接口。仓库中的其他 Maven 微服务模块仍保留源代码，供后续接入基础设施后继续开发；`启动.command` 不会启动它们。

## 关闭项目

双击 `关闭.command`，或执行：

```bash
./关闭.command
```

关闭脚本会停止当前项目启动的 Java 后端、商城端和管理端。日志与 PID 文件保存在 `.run/`，不提交到 Git。

## 常用开发命令

仅验证 Java 全量源码能否编译：

```bash
mvn -DskipTests package
```

仅启动 Java 演示后端：

```bash
mvn -pl shopping_demo spring-boot:run
```
